# Cold Email Writer

A personal Chrome extension that reads the LinkedIn profile you're viewing and writes a networking email from your template.

## Install

1. Unzip this folder somewhere you'll keep it (Chrome loads it from that spot).
2. Go to `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the `cold-email-writer` folder.
4. The settings page opens. Paste your template, check your persona, add your API key, and save.
5. Pin the extension (puzzle icon in the toolbar) so it's one click away.

## Use

1. Open a LinkedIn profile and click the extension icon. The side panel opens.
2. Click **Write email**. Add notes first if you have context, like a speaker series you attended.
3. Edit anything, then click **Open in Gmail** and paste in their email address.
4. For important contacts, click **Dig deeper** to search firm bios, news, and deals.

Tip: scroll down the profile once before clicking Write email so LinkedIn loads the experience and education sections.

## Updating

After changing any file, go to `chrome://extensions` and click the reload icon on the extension.
